# 网站后台（site-dashboard）

自己用的多网站后台：每个网站的访问量、在线状态，以及（可选）Google Search Console 和 Bing 的搜索数据。部署在 Vercel，不依赖任何 npm 包。

## 功能

- **访问量统计**：在网站里加一行统计代码即可。不用 cookie、不存 IP，按天统计页面浏览、访客、热门页面、来源、国家、设备。
- **在线监测**：每天检查一次每个网站能不能打开，也可以在后台点"立即刷新"。
- **Google 搜索数据（可选）**：点击、展示、平均排名、热门搜索词和页面，以及每个网址的收录状态。
- **Bing 数据（可选）**：点击、展示、热门搜索词、收录数。
- **变现判断**：按 28 天 Google 点击（5000）或 30 天页面浏览（1 万）给出"还早 / 接近 / 可以考虑变现"。

## 部署需要的东西

| 必需 | 说明 |
|---|---|
| Upstash Redis | Vercel 项目 → Storage → 创建 Upstash（Redis）免费数据库并连接到本项目，环境变量会自动加上 |
| 登录密码 | 第一次打开后台时在网页上设置，不需要环境变量 |

| 可选环境变量 | 作用 |
|---|---|
| `GSC_SERVICE_ACCOUNT_JSON` | Google 服务账号 JSON 文件的全部内容。服务账号邮箱要在每个网站的 Search Console 里加为用户（受限权限） |
| `BING_API_KEY` | Bing Webmaster → 设置 → API Access 里生成的密钥 |
| `CRON_SECRET` | 设置后，每日任务只接受 Vercel 自己的调用；不设置时每日任务限制为 20 小时最多跑一次 |
| `DASHBOARD_PASSWORD` | 用环境变量里的密码代替网页上设置的密码 |

改了环境变量后要重新部署一次。

## 接入一个新网站

1. 后台点"添加网站"，填名称和网址。
2. 打开这个网站的详情页，复制"统计代码"，加到网站每个页面的 `</head>` 前面。
3. 想排除自己的访问：在网站任意网址后面加 `?sd_ignore=1` 打开一次。
